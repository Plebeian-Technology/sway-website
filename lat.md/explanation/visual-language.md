# Visual language

The site looks like a campaign poster because the brand is a campaign button. The palette comes from the button and the page art, and the type pairing comes from the button's wordmark.

## Palette comes from the art

Every color in [[assets/css/style.css]] is taken from the logo button or the illustrations, so the page and its images never clash.

Navy is the logo ink and carries headings and buttons. Pink and sky blue are the two big bands behind the illustrations. Mist and rule are pale tints of the sky blue that separate sections without adding a new hue. The values are listed in [[reference/design-tokens]].

## Ultra matches the wordmark

The wordmark on the button is a fat Clarendon-style slab, and Ultra is a free face with the same build, so every headline reads as part of the logo.

Ultra is used only for headlines and the large statistic. Long text would tire the reader in a face this heavy, so body copy uses Public Sans, a civic sans-serif from the US Web Design System. The fallbacks keep the same split: a heavy Rockwell or Georgia for display, the system sans for text.

## One light theme

The brand is a light campaign poster, so the site has no dark theme.

Light only keeps one set of colors and art to maintain. The page has no animation, so there is no motion to reduce for readers who ask for less. Links and buttons show a visible focus outline in the navy ink, or in pale blue on the navy footer.
